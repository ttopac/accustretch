Forward validation of the assembled paper device. 246_v4_bd.png shows
the back-designed network of the run.

The meshed Abaqus input deck fwd_122_v4.inp (27 MB) is not tracked in
this repository because of file size. Download it from Google Drive.

https://drive.google.com/file/d/1ebbbDTi4KZfXK_zxAPWhOOQ8F8QmmHcF/view?usp=sharing

It can be rebuilt with 8_validation_assembly/genAbaqAssm.py, the macro
in S_logo_results/4_abaqusAssemblyMacro, and the mesh seeds in
S_logo_results/5_abaqusMeshingScripts.
