# Assembled Abaqus model

The assembled Abaqus model 246assm_v4.cae is not tracked in this
repository because of file size. Download it from Google Drive.

https://drive.google.com/file/d/1uuSH8kAk-DQpQ2HlHlZQ_-uIMxMffLES/view?usp=sharing

It can be rebuilt with 8_validation_assembly/genAbaqAssm.py, the macro
in S_logo_results/4_abaqusAssemblyMacro, and the mesh seeds in
S_logo_results/5_abaqusMeshingScripts. ExportingReadme.txt in this
folder documents how the deformed geometry is exported toward
fabrication (Abaqus to SAT to SolidWorks to Creo).
